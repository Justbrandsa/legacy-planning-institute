# Legacy Planning Institute website

Vercel-ready Next.js website with responsive marketing pages, service routes, validated lead forms, compliance pages, tracking hooks and supplied brand photography.

## Run locally

```bash
npm install
npm run dev
```

## Before launch

- Add the business WhatsApp number to the WhatsApp URL in `components/Site.tsx`.
- Connect `app/api/leads/route.ts` to an approved email provider or CRM.
- Populate `.env.local` from `.env.example` and load the selected analytics scripts.
- Confirm the FSP number and legal wording with the appointed compliance officer.
- Have the Privacy Policy and Terms of Use reviewed by a qualified adviser.
